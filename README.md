## Descripción

La presente actividad tiene como finalidad fortalecer los conocimientos de Programación Orientada a Objetos (POO) mediante la resolución de ejercicios prácticos en la plataforma HackerRank.

Para el desarrollo de esta práctica se seleccionaron ejercicios pertenecientes a las categorías:

* Object Oriented Programming
* Exception Handling
* BigNumber

Los ejercicios fueron resueltos utilizando el lenguaje Java, aplicando conceptos como encapsulamiento, herencia, polimorfismo, manejo de excepciones, abstracción y uso de clases especializadas para el manejo de números de gran precisión.

---

## Objetivos

### Objetivo General

Aplicar los principios de Programación Orientada a Objetos mediante la resolución de problemas prácticos en Java.

### Objetivos Específicos

* Utilizar clases y objetos para modelar soluciones.
* Implementar mecanismos de herencia y polimorfismo.
* Aplicar el manejo adecuado de excepciones.
* Utilizar las clases BigInteger y BigDecimal para operaciones numéricas de alta precisión.
* Desarrollar habilidades de análisis y resolución de problemas mediante programación.
